# Аффинитивный анализ чеков покупок

Учебный проект по анализу покупательских корзин. На основе данных чеков исследуются товары и категории, которые чаще всего приобретаются вместе, а также временные и стоимостные характеристики покупок.

## Данные

Файл [`cheki.csv`](./cheki.csv) содержит 1 943 записи и 5 признаков:

- `Фамилия_Номер_покупки` — идентификатор покупателя и номер покупки;
- `Продукт` — наименование товара;
- `Стоимость` — стоимость товара;
- `Тип` — категория товара;
- `Время покупки` — время совершения покупки.

## Содержание ноутбука

Основной анализ выполнен в [`affitiny_analysis.ipynb`](./affitiny_analysis.ipynb) и включает:

- загрузку, переименование и предварительную обработку данных;
- формирование покупательских корзин по покупателю и номеру покупки;
- подсчёт совместной встречаемости товаров;
- построение матрицы совместных покупок;
- расчёт нормализованной аффинитивности с использованием коэффициента Жаккара;
- визуализацию связей товаров в виде тепловых карт и графа ассоциаций;
- анализ совместных покупок на уровне категорий;
- исследование активности и суммарных расходов по часам;
- тепловую карту зависимости времени покупок от категорий;
- определение наиболее востребованных товаров;
- анализ распределения стоимости по категориям и покупателям с помощью boxplot и violinplot;
- сравнение среднего чека и структуры покупок разных покупателей;
- построение классификационного дерева решений для анализа зависимости целевого признака от характеристик данных.

## Основные результаты

Анализ позволяет выявлять наиболее сильные связи между товарами и категориями, определять периоды наибольшей покупательской активности, сравнивать структуру расходов разных покупателей и визуально исследовать полученные закономерности.

## Стек технологий

- **Python**;
- **Jupyter Notebook** — выполнение и документирование анализа;
- **Pandas** — загрузка, преобразование и группировка данных;
- **NumPy** — численные вычисления;
- **Matplotlib и Seaborn** — графики, тепловые карты, boxplot, violinplot и barplot;
- **NetworkX** — построение графа связей между товарами;
- **scikit-learn** — `DecisionTreeClassifier`, `LabelEncoder` и `train_test_split`;
- **Graphviz** — визуализация дерева решений;
- **CSV** — исходный формат данных.

## Установка и запуск

Установите зависимости Python:

```bash
pip install pandas numpy matplotlib seaborn networkx scikit-learn graphviz jupyter
```

Для отображения дерева решений также должен быть установлен системный пакет Graphviz.

Запустите Jupyter Notebook из каталога проекта:

```bash
jupyter notebook
```

Затем откройте файл `affitiny_analysis.ipynb` и выполните ячейки последовательно.
