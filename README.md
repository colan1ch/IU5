## Структура репозитория

```text
IU5/
├── Сем1/
├── Сем2/
├── Сем3/
├── Сем4/
├── Сем5/
├── Сем6/
├── .gitmodules
└── README.md
```

Каталоги `Сем1`–`Сем6` содержат материалы соответствующих семестров. Файл `.gitmodules` описывает подключённые проекты и их расположение в общей структуре.

## Клонирование

Чтобы скачать основной репозиторий вместе со всеми подключёнными проектами:

```bash
git clone --recurse-submodules https://github.com/colan1ch/IU5.git
```

Если основной репозиторий уже был склонирован без подмодулей, их можно получить командой:

```bash
git submodule update --init --recursive
```
