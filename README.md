## Структура репозитория

```text
IU5/
├── Сем1/
├── Сем2/
├── Сем3/
├── Сем4/
├── Сем5/
├── Сем6/
├── .gitmodules
└── README.md
```

Каталоги `Сем1`–`Сем6` содержат материалы соответствующих семестров. Все самостоятельные проекты, вынесенные в отдельные репозитории, подключены в общей структуре через `.gitmodules` как Git-подмодули.

## Клонирование

Чтобы скачать основной репозиторий вместе со всеми подключёнными проектами:

```bash
git clone --recurse-submodules https://github.com/colan1ch/IU5.git
```

Если основной репозиторий уже был склонирован без подмодулей, их можно получить командой:

```bash
git submodule update --init --recursive
```
